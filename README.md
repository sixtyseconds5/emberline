Emberline is a 2D arena survival game: fly one ship through ten waves of ember hostiles, pick an upgrade between waves, spend a full overdrive meter for a burst, and bring down the Maw on wave 10. It runs in a desktop browser from static files, with no network request.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.

## Play

- WASD / Arrows — fly the ship
- Mouse, hold click / Space — aim and fire
- Shift — dash through danger
- E — overdrive when the meter is full
- 1 / 2 / 3 — pick an upgrade between waves
- P pause · M mute · R restart
